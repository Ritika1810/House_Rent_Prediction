 🏠 House Rent Prediction

This is a beginner Machine Learning project using Linear Regression.

## 📊 Project Overview
In this project, I built a model to predict house rent based on:
- BHK
- Size
- Number of Bathrooms

## 🛠 Steps Performed
- Data Cleaning
- Feature Selection
- Train-Test Split
- Model Training using Linear Regression
- Model Evaluation using R² Score

## 📈 Model Performance
R² Score: 0.35

## 🧠 What I Learned
- Supervised Learning
- Regression Problems
- Overfitting
- Model Evaluation
